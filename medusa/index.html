PYCORA MEDUSA

Pycora Medusa V2.3.0 is a lightweight Python Static Site Generator built with 11ty free collections concept and no hardcode. Built on Axcora CSS 10kb, it offers automatic TOC, prev/next navigation, related posts by tags, dynamic pagination with pagination.first_url, RSS, JSON, Atom feeds, sitemap, and SEO-ready output. Every folder in content automatically becomes its own collection without config. Part of Axcora Ecosystem, open source, MIT licensed, fast and minimal for modern JAMstack websites.
