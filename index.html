Pycora Knowledge Altar

Complete CLI guide, installation commands, frontmatter syntax, and deployment rituals directly from pycora.axcora.com.

🔍

Pycora by Axcora is a Python static site generator. Like Jekyll and Eleventy, but in Python. You write Markdown with YAML frontmatter, it compiles to static HTML via Jinja2 and PAX templates.

Nyiblorong version is simple mantra, Medusa version is 11ty-like with full Jinja fix.

One command, no Node:

# FOR NYI BLORONG VERSION SIMPLE AND FAST !! RUN THIS COMMAND git clone -b nyi-blorong https://github.com/mesinkasir/pycora.git # FOR MEDUSA VERSION COMPLETE SETUP - RUN THIS COMMAND git clone https://github.com/mesinkasir/pycora.git # THEN RUN INSTALLATION python install.py python run.py python ssg.py # output/ ready to deploy # DEV MODE python dev.py open localhost://8000

Same as Jekyll — YAML block with ---. Pycora reads title, description, date, layout, tags and injects to Jinja2/PAX.

--- title: "The Gorgon Paradigm" date: "2026-08-08" layout: "article.html" tags: ["python", "ssg", "axcora"] --- # Content here...

Just CDN in base layout. No build step.

# Axcora CSS Injection https://cdn.jsdelivr.net/npm/axcora-css@1.0.1/axcora.min.css # Axcora JS Injection https://cdn.jsdelivr.net/npm/axcora-js@1.0.1/axcora.min.js

Jekyll needs Ruby, Eleventy needs Node. Pycora needs only Python.
Nyiblorong was like Jekyll simple, supports collections, pagination, JINJA layouts.
Medusa is like Eleventy modern — supports collections, pagination, JINJA + PAX layouts.

Zero legacy deps, works with Python 3.8+.

output/ is pure static:

  • Cloudflare Pages: Build python ssg.py, output output
  • GitHub Pages: Push output/ to gh-pages
  • Vercel / Netlify: Same, output dir is output/
  • Apache/NGINX: Copy output/ to /var/www/html
