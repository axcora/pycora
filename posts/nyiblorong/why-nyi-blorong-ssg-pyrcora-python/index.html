Nyiblorong Python SSG - Bootstrap 5 Classic

Nyiblorong is original Pycora version at pycora.axcora.com - built with Bootstrap 5.

Features:

  • Bootstrap 5 ~60kb CSS + JS
  • Hardcoded posts collection
  • sort_by: date only
  • Simple pagination
  • No prev/next
  • Relative URL (causes 404 at /blog/page/2/)

Good for:

  • Starter who knows Bootstrap
  • Quick blog with Bootstrap components
  • Familiar grid system

Limitations:

  • Heavy
  • Hardcoded
  • No free collections
  • URL bug at pagination page 2

That’s why we created Medusa Version - 5x lighter with Axcora CSS and free collections!

But Nyiblorong still works and stable for those who love Bootstrap. s
